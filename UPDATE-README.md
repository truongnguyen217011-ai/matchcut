# Cap nhat tu dong

Co the them kiem tra phien ban khi da co noi host release. Dat URL manifest vao bien moi truong `MATCHCUT_UPDATE_MANIFEST_URL`.

Manifest mau:

```json
{
  "version": "1.0.1",
  "url": "https://example.com/MatchCut-portable.zip",
  "sha256": "..."
}
```

Chua bat auto-update mac dinh vi chua co URL phat hanh chinh thuc.
